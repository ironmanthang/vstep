# VSTEP Official Content Sourcing Index

This directory maintains the source citations, original transcripts, reference texts, and examination links for all VSTEP learning modules across the 4 skills and Full Mock Test simulations.

## Sourcing Policy
- **Authentic Institutions Only**: All questions, listening audio transcripts, reading passages, writing prompts, and speaking cards are sourced from accredited institutions (ULIS, HNUE, HCMUE, Cambridge/CEFR standards).
- **Docs Over Schema Baggage**: Provenance and citations are maintained exclusively in Markdown files in this directory to keep runtime TypeScript code and schemas lean.
